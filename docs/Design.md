## Overview

Open Workspace creates a professional dark space for AI-powered work — deep blues (#4f6bff) that convey technological intelligence, clean data visualization, and the focused clarity of a late-night coding session. Every element communicates: "Let's build something great."

## Colors

The palette is anchored by #4f6bff as the primary accent, with #4f6bff in dark mode.

### Foundation

Open Workspace's color story centers on **intelligent blue** (#4f6bff) — a vibrant, confident blue that conveys AI capabilities and professional focus. This is paired with deep neutrals and clear data visualization colors.

### The Intelligent Blue System

**Primary — Open Blue (#4f6bff)**: The signature tech color — used for primary actions, AI-related highlights, and the app's recognizable identity. Vibrant but professional.

**Secondary — AI Purple (#8b5cf6)**: A complementary purple for secondary AI elements and supporting UI. Establishes hierarchy while maintaining tech feel.

### Surface Hierarchy

|-------|-----------|-----------|-----|
| Canvas | #f8f9fc | #0e0f14 | Cool gray background |
| Surface | #ffffff | #1c1e26 | Cards, elevated elements |
| Muted | #f1f3f8 | #15171e | Subtle backgrounds |
| Border | #e2e8f0 | #2a2d3d | Subtle definition |

### Dark Mode: "Late Night Building"

Dark mode transforms Open Workspace into a focused late-night workspace — deep cool gray (#0e0f14) lets blue accents glow while reducing eye strain for extended AI collaboration sessions.

**Core Principles:**

1. **Blue Glows**: The signature blue (#4f6bff) remains vibrant against dark backgrounds
2. **Deep Cool Canvas**: Not pure black — #0e0f14 has subtle blue undertone that feels technical
3. **Data Visibility**: Critical information remains high-contrast for quick scanning

**Dark Mode Token Mapping:**

| Light Mode | Dark Mode | Rationale |

## Elevation & Depth

### Shadow Philosophy

Open Workspace uses **layered shadows** — moderate depth that creates clear hierarchy without feeling heavy. The effect is professional and focused.

| Level | Treatment | Use |
|-------|-----------|-----|
| Level 0 | none | Flat elements |
| Level 1 | 0 1px 2px rgba(0,0,0,0.05) | Subtle hover |
| Level 2 | 0 4px 6px rgba(0,0,0,0.07) | Cards, dropdowns |
| Level 3 | 0 10px 15px rgba(0,0,0,0.1) | Elevated panels |
| Level 4 | 0 20px 25px rgba(0,0,0,0.12) | Modals |
| Level 5 | 0 25px 50px rgba(0,0,0,0.15) | Maximum elevation |

### Border Usage

Subtle borders (1px, #e2e8f0 light / #2a2d3d dark) for definition. Open Workspace uses borders in combination with shadows for clear element separation.

## Components

### Buttons & Interaction

**Primary CTA**: Open Blue (#4f6bff) background, white text, 6px rounded corners. On hover: brightens to #6b8bff. On press: darkens to #3b5aed. The confident AI action.

**Secondary**: AI Purple (#8b5cf6) background for secondary actions. Establishes hierarchy while maintaining tech feel.

**Ghost Buttons**: Transparent with subtle blue border — for tertiary actions.

### Cards & Containers

**Workspace Cards**: Surface background, subtle border, layered shadow. The card displays collaborative content — code snippets, AI suggestions, project data.

**Data Cards**: Clean layout with clear data hierarchy. Numbers are prominent, labels are scannable.

### Inputs & Selection

**Text Inputs**: Surface background, subtle border, 6px radius. Focus state: blue border with soft glow. Placeholder uses muted gray.

**Select Dropdowns**: Consistent with input styling. Dropdown uses level-2 shadow.

**Checkboxes**: Custom styled — blue check when active.

**Switches**: iOS-style toggle — blue when active, gray when inactive.

### AI Collaboration Features

**Code Blocks**: Dark surface (#1e2030), monospace font, syntax highlighting with the blue-purple palette.

**AI Suggestions**: Blue-tinted background, distinguished from human content.

## Do's and Don'ts

### Do

- **Use Open Blue for primary CTAs** — it's the tech anchor, immediately recognizable
- **Apply layered shadow elevation** — professional depth, not flat, not dramatic
- **Prioritize data scanability** — technical content must be immediately parseable
- **Use blue-purple tech palette** — professional, not playful
- **Maintain blue brightness in dark mode** — it stays vibrant
- **Use subtle borders with shadows** — clear element separation

### Don't

- **Don't use aggressive colors** — blue-purple is confident, not flashy
- **Don't make shadows too dramatic** — keep elevation professional, focused
- **Don't use pure black text** — cool gray (#0e0f14) maintains technical feel
- **Don't make data hard to scan** — hierarchy must be unmistakable for technical content
- **Don't use rounded corners > 8px** — keep elements crisp, technical
- **Don't treat this as consumer app** — it's professional AI collaboration infrastructure
